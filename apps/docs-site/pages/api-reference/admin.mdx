Platform administration. The audit trail is readable by super-admins only.

## `GET /api/v1/admin/audit-logs` 🔒

**Query the immutable admin audit trail (super_admin only)**

State-changing admin actions (dispute resolutions, fraud flag reviews, webhook replays) with actor, target, before/after state and request context, newest first. Entries are append-only: POST/PUT/PATCH/DELETE return 405 and the database rejects modification. Entries older than 365 days are purged by a daily retention job.

**Parameters**

| Name | In | Type | Notes |
|------|----|------|-------|
| `actorId` | query | string | optional |
| `action` | query | string | optional (one of `trade.dispute_resolved`, `fraud_flag.reviewed`, `webhook.replayed`, `user.banned`, `user.unbanned`, `kyc.approved`, `kyc.rejected`) |
| `targetType` | query | string | optional (one of `trade`, `fraud_flag`, `webhook_event`, `user`, `kyc`) |
| `targetId` | query | string | optional |
| `from` | query | string | optional |
| `to` | query | string | optional |
| `page` | query | integer | optional (min 1, default `1`) |
| `limit` | query | integer | optional (min 1, max 100, default `20`) |
