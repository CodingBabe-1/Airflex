# Airflex UI Component Library

Welcome to the Airflex UI component library catalog. All shared primitives located under `frontend/components/ui/` are built with accessible HTML semantics, comprehensive dark mode styling, and responsive layout foundations.

---

## Component Index & Props Reference

### 1. Badge (`Badge.tsx`)
A status badge representing trade lifecycle states or system statuses with accessible contrast and optional status dot indicator.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `"Open"` \| `"Active"` \| `"Locked"` \| `"Completed"` \| `"Cancelled"` \| `"Disputed"` | `"Open"` | Trade status variant determining background and text tones. |
| `showDot` | `boolean` | `true` | Toggles the colored status dot indicator. |
| `children` | `React.ReactNode` | Status name | Custom text or content within badge. |
| `className`| `string` | `""` | Additional CSS class overrides. |

---

### 2. Button (`Button.tsx`)
Polymorphic or standard button supporting visual variants, sizes, loading spinners, and disabled states.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `"primary"` \| `"secondary"` \| `"danger"` \| `"ghost"` | `"primary"` | Visual tone and emphasis of the button. |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Button padding and typography scale. |
| `isLoading` | `boolean` | `false` | Shows spinner and accessible loading indicator while disabling interaction. |
| `loadingText` | `string` | `"Loading..."` | Screen-reader label and visual text during loading. |
| `disabled` | `boolean` | `false` | Disables button events and dims visuals. |

---

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |

| `children` | `React.ReactNode` | — | Card content. |

### 7. Spinner (`Spinner.tsx`)
Accessible SVG loading spinner with `role="status"` and visually-hidden assistive label.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Spinner dimensions (16px, 24px, 32px). |

---

### 8. Table (`Table.tsx`)
Theme-tokenised table sub-primitives ensuring WCAG contrast in both light and dark themes.

- **`Table`**: Root table container with accessible `caption` (aria-label).
- **`THead`**: Header section with uppercase tracking and subtle border dividers.
- **`TBody`**: Body container with row dividers.
- **`TR`**: Table row supporting hover animations and `selected?: boolean` active row highlighting.
- **`TH`**: Header cell with `scope="col"`.
- **`TD`**: Data cell with responsive horizontal padding.
- **`TableEmptyState`**: Centered empty table placeholder supporting `colSpan?: number`.
